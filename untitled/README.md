**Padrão Comportamental = Template Method** : esse padrão define o esqueleto de um algoritmo em uma classe base, delegando a implementação de algumas etapas específicas para as subclasses. Na sua implementação, as subclasses podem redefinir certas etapas do algoritmo sem alterar a sua estrutura principal, garantindo a ordem de execução dos métodos que é definida e imutável na classe mãe. No exemplo, `RelatorioBase` define o template de relatório com os passos, permitindo que `RelatorioVendas` e `RelatorioFinanceiro` personalizem partes específicas.
